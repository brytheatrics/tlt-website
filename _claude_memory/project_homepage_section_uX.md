Flagged 2026-05-12 while iterating on the redesigned `/home/`:

The homepage currently groups content into six fixed numbered sections — "01 Onstage", "02 Education", "03 Beyond the Stage", "04 Get Involved", "05 Support", "06 With Gratitude". Visually this works well, but **operationally** it's a problem:

- The person running the site daily has to decide where each new promo or one-off lives.
- Example Blake gave: where does a new **Off the Shelf** show go? "Onstage" or "Beyond the Stage"? Reasonable case for both — that ambiguity will create inconsistency over time as different editors guess.
- Many announcements are genuinely one-offs that don't cleanly fit any of the six labels.

**Why:** A rigid taxonomy on the homepage forces editors to be miniature information architects every time they post. That fights against day-to-day usability.

**How to apply:** Two options to keep in mind when the homepage is revisited:

1. **Reduce the numbered structure to just 2-3 always-on groups** (e.g. Current Season, Education, Sponsors) and add an explicit *"Ad Hoc"* / *"Featured"* zone where the editor can drop one-off blocks with their own headline. New block = new headline, no taxonomy decision required. Old block deleted = no visual scar.
2. **Drop the numbered scheme entirely** and let each promotional block carry its own self-contained headline, with the editorial polish coming from typography + rule lines + photos rather than a global numbering system.

Either way, the goal is: an editor who isn't a designer should be able to post a new promo in 30 seconds without having to decide which category it belongs to.

**Clarification 2026-05-12 follow-up:** Blake noted that "Onstage" is currently *only* the season-scroller — there's no other content under that section header. So in practice, off-mainstage shows (Off the Shelf, special readings, etc.) don't have an obvious home; the realistic workflow is **add a new ad-hoc section for each one-off promotion**, rather than slotting it into an existing taxonomy. This pushes the design clearly toward Option 1 above: keep the season scroller as the only fixed "Onstage" thing, and treat everything else (Education, Special Events, Get Involved, Off the Shelf shows, one-offs) as flexible blocks the editor adds/removes with their own headlines as needed.

Don't redo this until Blake explicitly asks — this is a "later" note, not a current task.
