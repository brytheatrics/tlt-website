`\\TLT-SERVER\` is the file share at Tacoma Little Theatre. Mounted/accessible from Blake's Windows machine via UNC path (use `//TLT-SERVER/` in bash on this machine).

Top-level folders include: TLT Photos, TLT Programs, TLT Archive, Marketing, TLT Videos, Seasons, History, Education, Special Events, TLT Scripts, plus admin folders (Accounting, Business, Cast and Crew Information, IT, home, homes — DO NOT browse, private/sensitive).

Folder naming convention for season-organized content: `YYYY` where digits = last 2 of each year (e.g. `1213` = 2012-2013, `2425` = 2024-2025).

Strict rules:
- **READ-ONLY.** Never delete, move, or modify anything on this share. Boss set up the server; lost data = serious consequences.
- **TLT Videos are archive-only** (filmed under licensing terms that forbid public posting). Do not link to or upload these to any public site.
- **Don't browse private folders** even when given general "look around" permission.
